# bb pr update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `bb pr update -p ID [-T title] [-d desc | --description-file PATH]` (+ stdin JSON) so users/agents can edit a PR's title and/or description instead of declining and recreating the PR.

**Architecture:** A new client method `PRResource.Update` fetches the current PR, overlays any non-empty provided fields (title/description) onto the current values, and `PUT`s the merged body — mirroring the existing `AddReviewer` fetch-then-merge pattern. This guarantees Bitbucket's API-required `title` is always present and never accidentally clears the description. A thin `pr update` Cobra command builds the input from flags or stdin, enforces "at least one field", and prints the updated PR.

**Tech Stack:** Go 1.26, Cobra, stdlib `net/http`; tests use stdlib `net/http/httptest` via `newTestClient`.

## Global Constraints

- No new third-party dependencies.
- ASCII punctuation only in all code, comments, and docs (no em-dashes, en-dashes, smart quotes, or the ellipsis character).
- Bitbucket's `PUT pullrequests/{id}` requires `title` and is a partial update (omitted fields preserved) — established by the existing `AddReviewer`, which `PUT`s only `{title, reviewers}` without wiping descriptions. `Update` therefore sends `{title, description}` merged from the current PR. VERIFY-DURING-TDD: if a real call ever shows full-replace semantics (reviewers/destination cleared), expand the merged body to also carry those from the fetched PR. This does not block the plan.
- `pr update` edits **title and description only** this slice (no destination branch, no reviewers).
- Empty string means "not provided" (falls back to the current value); clearing a field to empty via flags is out of scope (YAGNI).
- `--pr-id`/`-p` is required (it addresses the PR in the URL, not the body) and stays `MarkFlagRequired` even though the command is stdin-capable.
- Flags mirror `pr create` exactly: `-T/--title`, `-d/--description`, `--description-file` (reuse `resolveTextBody`).
- Docs sync (README.md, llms.txt, CLAUDE.md) and the `--describe` manifest (`commandRegistry`, `typeRegistry`, regenerated golden) are REQUIRED for the new leaf.
- Never push to git/Bitbucket without explicit user sign-off. Commit trailer: `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`.

```go
// Update edits a pull request's title and/or description. Bitbucket's PUT
// requires the title and treats the body as a partial update, so Update first
// fetches the current PR, overlays any non-empty fields from input onto the
// current values, then PUTs the merged result. This keeps the required title
// present and never clears the description for a title-only edit.
func (r *PRResource) Update(ctx context.Context, prID int, input UpdatePRInput) (PR, error) {
	current, err := r.Get(ctx, prID)
	if err != nil {
		return PR{}, fmt.Errorf("get PR: %w", err)
	}
	body := UpdatePRInput{Title: current.Title, Description: current.Description}
	if input.Title != "" {
		body.Title = input.Title
	}
	if input.Description != "" {
		body.Description = input.Description
	}
	data, err := r.client.do(ctx, "PUT", r.prPath(prID), body, nil)
	if err != nil {
		return PR{}, err
	}
	return decode[PR](data)
}
```

```go
var (
	prUpdateID              int
	prUpdateTitle           string
	prUpdateDescription     string
	prUpdateDescriptionFile string
)

var prUpdateCmd = &cobra.Command{
	Use:   "update",
	Short: "Update a pull request's title and/or description",
	RunE: func(cmd *cobra.Command, args []string) error {
		ws, r, err := workspaceAndRepo()
		if err != nil {
			return err
		}
		description, err := resolveTextBody(prUpdateDescription, prUpdateDescriptionFile, "description", "description-file")
		if err != nil {
			return err
		}
		var input bitbucket.UpdatePRInput
		if _, err := stdinInputOr(&input, func() bitbucket.UpdatePRInput {
			return bitbucket.UpdatePRInput{
				Title:       prUpdateTitle,
				Description: description,
			}
		}); err != nil {
			return err
		}
		if input.Title == "" && input.Description == "" {
			return newCLIError(ErrCodeValidationFailed,
				"nothing to update: provide --title and/or --description (or pipe JSON on stdin)", nil)
		}
		pr, err := client.PRs(ws, r).Update(context.Background(), prUpdateID, input)
		if err != nil {
			return err
		}
		return printOutput(pr, func() {
			fmt.Printf("PR #%d updated: %s\n", pr.ID, pr.Links.HTML.Href)
		})
	},
}
```
